# Frontend Libraries

Frontend Libraries are the primary curated library surface in Hub.

These are the libraries Zebflow projects use directly in TSX (beyond
`zeb/react` and `zeb/ui`, which need no install):

- `zeb/d3`
- `zeb/deckgl`
- `zeb/codemirror`
- `zeb/markdown`
- `zeb/pdf`
- `zeb/prosemirror`
- `zeb/threejs`
- `zeb/threejs-vrm`
- `zeb/graphui`
- `zeb/livegeo`
- `zeb/use`

This area should help a user answer two questions fast:

1. which library should I use?
2. what does the source look like in a normal Zebflow page?

The child entries under this menu go to the specific library families.
