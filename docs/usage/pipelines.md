# Pipelines

Pipelines are backend workflows represented as graphs.

Use pipelines for:

- webhooks
- APIs
- scheduled work
- function calls
- file conversion
- database reads and writes
- AI calls
- map publishing
- realtime events

Pipelines should behave like visual Rust: data should move only where it is needed, large values should use references or files, and logs should be explicit when high throughput matters.
