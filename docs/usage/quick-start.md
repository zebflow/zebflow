# Quick Start

1. Start Zebflow with `zebflow`.
2. Open `http://localhost:10610/login`.
3. Create or open a project.
4. Create a page in Project Studio.
5. Add a pipeline when you need backend logic.
6. Store data in Sekejap DB or connect an external database.
7. Share reusable work through Hub.

The first project can stay small. Zebflow is designed so the same project can later grow into APIs, maps, background jobs, AI tools, and deployable apps.
