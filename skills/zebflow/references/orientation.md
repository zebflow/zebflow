# Zebflow Orientation

Zebflow is one runtime for building and running full-stack apps.

Core surfaces:

- Project Studio for editing project work.
- Reactive web templates for pages and apps.
- Pipelines for backend workflows.
- Sekejap DB for embedded multi-model data.
- Files for uploads, generated artifacts, media, and datasets.
- Mapserver for spatial publishing and querying.
- Hub for shareable packages.
- MCP for controlled project tooling.

Default product direction:

- Make useful software without requiring many separate stacks.
- Keep installation simple through `npm`, `pip`, Docker, and source builds.
- Treat project artifacts as inspectable, shareable, and portable.
- Prefer visual Rust behavior: minimal implicit work, explicit boundaries, and efficient data movement.

Audience:

- global users
- full-stack developers
- researchers
- builders who want fewer moving parts
- teams sharing reusable project assets

Writing style:

- direct
- short
- practical
- friendly
- no inflated claims
